# Calculadora de Indenização — Heloísa Hommerding Advocacia

Landing page com calculadora interativa de indenização por acidente de trabalho.

**Acesse:** https://heloisaadv.github.io/calculadora-indenizacao/

## Recursos

- Calculadora em 3 passos com prévia em tempo real do valor estimado
- Animações de scroll, parallax sutil no hero e contadores animados
- Micro-interações (ripple nos botões, validação visual em tempo real, hover refinado)
- Totalmente responsivo
- Integração direta com WhatsApp da equipe
